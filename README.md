# 🖨️ 印刷厂生产管理系统

面向中小型印刷厂的生产管理系统，覆盖 **订单管理、纸张材料、机台排产、印前/印刷/装订工序进度、交期预警、返工跟踪** 全流程。

- **后端**：Django 5 + Django REST Framework + SQLite
- **前端**：Vue 3 + Element Plus（无构建，本地静态资源，离线可用）
- 内置 5 家客户、7 种纸张、5 台机台、8 个覆盖各状态的样例订单、排产计划与返工单

## 快速开始

```bash
cd printing_system
bash start.sh
# 或手动执行：
#   pip install -r requirements.txt
#   python manage.py migrate
#   python manage.py seed        # 写入/重置样例数据（可重复执行）
#   python manage.py runserver
```

浏览器打开 <http://127.0.0.1:8000>

> 样例日期按运行当天相对生成，保证"逾期 / 紧急 / 预警"数据在任何时候都有效。

## 功能模块

| 模块 | 功能 |
|------|------|
| 📊 生产看板 | 在制/逾期/返工/低库存统计卡；交期三级预警（逾期、≤2天紧急、≤5天预警）；近7日机台负荷图；订单状态分布、机台概况、纸张批次效期预警（已过期/临期）、低库存清单，全部可点击下钻 |
| 📋 订单管理 | 订单新建/编辑/筛选（关键字、状态、客户、交期级别）；列表内嵌三工序流水线与进度条；详情抽屉维护工序进度、排产、返工 |
| 📦 纸张材料 | 纸张库存、安全库存预警、库存金额；**批次化管理：入库登记批次号/到货日期/保质期（天数或到期日），出库按 FEFO 先到期先出自动分配各批次、可手动调整；已过期与临期(≤30天)批次横幅+行内+看板三级提醒；展开纸张可看各批次剩余张数；出入库流水记录批次去向，出库超量拦截** |
| 🏭 机台排产 | 按日期浏览各机台任务（日历式排产表）、班次、计划/实际产量与完成率；机台增删改与状态（生产中/空闲/维保）随排产自动联动 |
| 🔧 返工跟踪 | 返工单全生命周期：待处理 → 返工中 → 已闭环；记录工序、原因（色差/套印/划伤/装订/材料）、数量、责任人、问题描述与处理结果 |

### 工序与订单状态联动

印前 → 印刷 → 装订三道工序各自有状态（未开始/进行中/已完成/返工中）与 0–100% 进度：

- 更新工序进度后**订单主状态自动推导**（印前中 → 印刷中 → 装订中 → 已完成）；
- 登记返工单后，对应工序与订单自动进入 **返工中**；
- 返工闭环后工序自动恢复为进行中，订单回到实际工序；
- 全部工序完成自动记录完工日期。

### 纸张批次与 FEFO 效期管理

- **入库即建批**：每次入库必填批次号、到货日期，保质期可填「天数」（自动算到期日）或直接选到期日，也可标记无保质期；同一批次号再次到货自动累加，新批次号建立独立批次档案。
- **出库 FEFO**：出库时按「先到期先出」自动带出各批次扣减数量（临期、过期批次优先），可在弹窗中逐批手动调整，合计必须等于出库数量；分配到已过期批次会二次强提醒。
- **效期预警**：距到期 ≤30 天记为「临期」、已过到期日记为「已过期」；纸张页顶部横幅、库存行底色与效期列、展开后的批次余量，以及看板右侧「纸张批次效期预警」面板三处同步提醒，点击即可下钻。
- **账实勾稽**：同一规格总库存 = 各批次剩余之和；每条出入库流水都带批次号，可追溯纸是哪批进、哪天到、领到哪个订单。
- 旧数据执行迁移时会自动补建「期初批次」并把历史流水挂接过去，不会丢流水。

## 主要 API

| 接口 | 说明 |
|------|------|
| `GET /api/dashboard/` | 看板汇总（统计、预警订单、纸张批次过期/临期、低库存、7日负荷） |
| `GET/POST /api/orders/`、`PATCH /api/orders/{id}/` | 订单 |
| `GET/PATCH /api/orders/{id}/progress/` | 三工序进度（服务端校验 0–100 与状态一致性） |
| `GET/POST /api/schedules/`、`PATCH /api/schedules/{id}/` | 机台排产 |
| `POST /api/papers/{id}/stock_in/` | 批次入库（batch_no、arrival_date、shelf_life_days 或 expiry_date） |
| `POST /api/papers/{id}/stock_out/` | 批次出库（默认 FEFO 自动分配，可传 allocations 手动指定各批次数量） |
| `GET /api/papers/{id}/fefo_plan/?quantity=n` | 预览 FEFO 各批次出库分配方案 |
| `GET /api/paper-transactions/` | 出入库流水（含批次号与保质期） |
| `GET/POST /api/reworks/`、`PATCH /api/reworks/{id}/` | 返工单 |
| `GET/POST /api/machines/`、`/api/customers/` | 机台、客户 |

另可访问 Django Admin：`python manage.py createsuperuser` 后登录 <http://127.0.0.1:8000/admin/>。
